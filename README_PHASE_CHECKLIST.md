# FoodConnect phase verification checklist

- [ ] Phase 0: Python, venv, Git and `.gitignore` configured locally.
- [ ] Phase 1: `python app.py` starts and homepage loads.
- [ ] Phase 2: all eight SQLAlchemy tables exist in the SQLite database.
- [ ] Phase 3: signup, terminal/email OTP, verification and login work.
- [ ] Phase 4: restaurant suggestion, restaurant detail, review, rating and photo upload work.
- [ ] Phase 5: AJAX comments/reactions work; two separate browser sessions receive Socket.IO comment/reaction events.
- [ ] Phase 6: search, cuisine filter, price filter and six-item pagination work together.
- [ ] Phase 7: visited date, optional YouTube embed and map when coordinates exist work.
- [ ] Phase 8: lexical fallback works; after training in a compatible environment, `.tflite` and vocabulary files load and produce labels.
- [ ] Phase 9: responsive layout works at desktop/mobile widths; GSAP is optional enhancement.

Do not mark a checkbox complete until you have tested it on your own machine/browser.
